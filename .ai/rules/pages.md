# Pages

## Use governed interaction components by workflow purpose
Use GovernedAttachmentInput for repository-backed uploads, Questionnaire for sectioned conditional evidence-gated assessments with local draft autosave, ResponsivePanel for desktop Sheet/mobile bottom Drawer behavior, DocumentPreviewCarousel only for multi-item document/image/version previews, and Marker for provenance/checksum/version/source metadata. Do not use Carousel for dashboard cards.
