# Js Components Feature

## Pilot UAT evidence is governed, scoped, and non-fabricated
UAT campaigns pin an effective checksum-valid county catalogue. Required role-matched executions are immutable and county-scoped; failed/blocked runs create findings with independent resolution/verification; acceptance rechecks all latest scenario/county pairs and has independent immutable decisions. Seed only planning campaigns/scenarios—never executions, findings, or acceptance.
