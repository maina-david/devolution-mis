# Security Governance Feature

## Keep incident exercises labelled and closure independently evidenced
Security exercises must remain explicitly labelled and must never be presented as live incidents. Preserve the immutable event ledger, ordered response states, lead-only acknowledgement, independent closer, clean private DMS closure evidence, and mandatory privacy/legal reference for confirmed exposure. Automated tests are engineering proof, not evidence that a representative operational exercise occurred.
